SHAMAL BIRTHDAY WEBSITE — PHOTO SLIDESHOW UPDATE

Included pages:
- index.html — Home
- memories.html — 9-photo slideshow, one large photo per view, each with its own custom romantic note
- quiz.html — Love Quiz
- letter.html — Birthday Letter
- surprise.html — Final Surprise
- style.css and script.js
- assets/ — 9 optimized JPEG photos and original birthday instrumental melody

Preview:
Open index.html in a browser. On Memories, use Next memory / Previous or the dots to move through all nine photos. The slideshow works on mobile and desktop.

Publish to GitHub Pages:
1. Extract this ZIP.
2. Upload all files and the complete assets folder to the root of your existing repository.
3. Replace the older versions of the files.
4. Commit the changes.
5. Keep GitHub Pages set to deploy from main / (root).

All nine photographs are included as optimized JPEGs for faster loading and easier GitHub upload.
Music starts after the visitor taps the play button because browsers block automatic audio playback.
